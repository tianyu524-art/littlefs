Cache 可靠性设计：SECDED ECC 原理、SRAM 失效模式、MCA 错误处理流程与软件隔离机制

① SRAM 失效模式分类
Stuck-At 故障位元永久固定为 0 或 1，制造缺陷或离子辐射损伤
Transition 故障单元可以保持状态但无法完成 0→1 或 1→0 切换
Coupling 故障相邻 bitline/wordline 之间的寄生耦合导致互相干扰
BTI 老化NBTI/PBTI 导致 Vth 漂移，弱单元随时间变慢直至失效
软错误 (SEU)Alpha 粒子/宇宙射线翻转单元，无永久损伤，可纠正
保留故障漏电流超标，6T SRAM 内部节点电荷泄漏翻转状态
② SECDED ECC 位布局（32b数据 + 7b校验）
蓝=数据位，橙=Hamming校验位，紫=DED总体校验位
位置规则：校验位 Pi 位于 2i-1 处（P1=位1,P2=位2,P4=位4...）
P1 = XOR(位1,3,5,7,9,11...) P2 = XOR(位2,3,6,7,10,11...)
综合征(syndrome)非零→单bit纠错，综合征+总体校验→双bit检测
③ Cache line 硬件冗余：行/列替换
与 DRAM 相同，SRAM 阵列具备冗余行/列（典型 L3：每个 bank 4冗余行 + 2冗余列）。
测试流程：晶圆分选(Wafer Sort) → MBIST 识别坏行/列 → 激光熔断/eFuse 编程修复 → 量产筛选
在线修复：AMD/Intel L3 支持运行时坏路禁用（减少关联度 16-way→14-way），避免整片 L3 失效
④ 错误处理软硬件协同流程
L3 ECC 电路检测1bit错误
↓
硬件自动纠正，写回正确值
无需软件
↓ 累计阈值(CMCI)
触发 CMCI 中断 → MCE Bank记录
↓
UEFI/BIOS: GHES ACPI报告
↓
OS MCE Handler: /dev/mcelog
↓ 物理地址解析
memory_failure() → hwpoison
↓
对应物理页设 PG_hwpoison
↓
应用收到 SIGBUS / 进程杀死
↓ 如为文件页
从磁盘重新读取(文件系统层恢复)
⑤ Cache 坏路软件隔离：x86 MCE MSR 接口详解
MCA Bank 寄存器 IA32_MCi_STATUS[63]: VALID
IA32_MCi_STATUS[62]: OVERFLOW
IA32_MCi_STATUS[61]: UC(Uncorrected)
IA32_MCi_STATUS[60]: EN(Enabled)
IA32_MCi_STATUS[57]: S(Signaling)
IA32_MCi_STATUS[56]: AR(Action Required)
IA32_MCi_ADDR: 故障物理地址
IA32_MCi_MISC: 恢复提示信息
Cache 坏路禁用 (Intel) BIOS 可通过 MSR_CACHE_CONTROL
写入坏路 bitmask 禁用特定 Way
例：32MB L3 16-way
禁用1路 → 30MB 有效容量
OS 对此透明，不感知容量变化
